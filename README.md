# صلوات‌شمار هوشمند (Salawat Counter)

اپلیکیشن حرفه‌ای اندروید برای شمارش صلوات با تشخیص صوتی هوشمند.

## تکنولوژی‌ها
- Kotlin
- Jetpack Compose
- MVVM
- Room Database
- SpeechRecognizer (تشخیص آفلاین در صورت پشتیبانی دستگاه)
- Foreground Service

## حداقل نسخه اندروید
Android 7.0 (API 24)

## ساخت پروژه
1. پروژه را در Android Studio باز کنید.
2. Sync Gradle.
3. برای ساخت APK امضا‌شده:
   - Build → Generate Signed Bundle / APK
   - Keystore خود را انتخاب کنید.

## انتشار در کافه‌بازار
APK امضا‌شده با keystore شخصی خودتان را آپلود کنید.

## ساختار پروژه
کد کامل در پوشه‌های app/src/main قرار دارد.
